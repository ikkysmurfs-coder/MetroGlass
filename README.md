<h1><a id="features"></a>Features</h1>

- **Liquid Glass Premium UI**: Clean Pure Black dark mode (#000000), White Glass light mode, and Metro Orange accent (#FF4D00).
- Stream any song or video from YouTube Music with background playback.
- Offline downloads, synced karaoke lyrics, smart queue, sleep timer, crossfade, and equalizer.
